# AWS Account Administration and Access Management

## Project Overview

This project documents AWS account administration and access management tasks completed for the Africa Neurocare & NeuroResearch Initiative (ANNI).

## Objectives

- Support organizational AWS account access.
- Manage IAM users and permissions.
- Configure access to AWS billing information.
- Redeem AWS credits for the organization.

## Tasks Completed

- Created IAM users to support organizational AWS account access.
- Configured administrative permissions for IAM users.
- Configured billing access permissions.
- Redeemed AWS credits for the organization.

## AWS Services

- AWS Identity and Access Management (IAM)
- AWS Account Administration
- AWS Billing

## Key Learnings

- IAM user management and permission configuration.
- Access management for organizational AWS accounts.
- AWS billing access and account administration.
- AWS credit redemption.

## Project Context

Work completed for the Africa Neurocare & NeuroResearch Initiative (ANNI).

This repository provides a high-level project summary and does not contain account credentials, internal configuration details, or confidential organizational information.
